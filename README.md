🚦 Traffic Flow Analysis using Data Science
📌 Project Overview
This project analyzes real-world traffic data to understand vehicle flow patterns, identify peak congestion hours, and study the impact of weather and time on traffic conditions.
The project includes:
* 📊 Data Analysis using Python
* 🌐 Interactive Dashboard using Streamlit
* 📈 Visualization Dashboard using Tableau
  
📁 Dataset
The dataset used in this project contains traffic-related information such as:
* `date_time` – Timestamp of traffic data
* `traffic_volume` – Number of vehicles
* `weather_type` – Weather condition
* `temperature`, `rain`, `snow`, etc.

📂 Dataset file: `traffic.csv`
🛠 Tools & Technologies Used

* 🐍 Python (Pandas, Matplotlib, Seaborn)
* 🌐 Streamlit
* 📊 Tableau Desktop
* ☁️ Tableau Public
